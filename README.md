# Absalom Ndinomwene Shishiveni — Portfolio

Personal portfolio for Absalom Ndinomwene Shishiveni, a BSc Computer Science (Honours) graduate from the University of Namibia and ISC2 Certified in Cybersecurity (CC).

## Live site

https://anshishiveni.github.io/

## Focus

The portfolio presents selected work and skills across:

- Software and mobile development
- IT support and troubleshooting
- Networking fundamentals
- Cybersecurity fundamentals
- Database-backed web applications

The flagship project is a 2026 Honours thesis: **Design and Evaluation of a QR-Code-Based Mobile Payment Prototype to Reduce Cash Dependency in Namibia**.

## Featured projects

- QR-Based Mobile Payment Prototype — React Native, Expo, Firebase, Node.js and Stripe sandbox
- NLP Quiz Generator — Python, Flask, NLTK, SQLAlchemy and SymPy
- Hospital Management System — Flask, SQLite and Bootstrap
- Namibia Hotel Booking System — Flask, SQLAlchemy, PostgreSQL and REST APIs
- Ace Technologies Website — HTML, CSS, JavaScript, PHP and MySQL

## Technology

- Semantic HTML
- Tailwind CSS utilities with custom CSS
- Vanilla JavaScript
- GitHub Pages
- GitHub Actions for asset-path validation

The site is a static GitHub Pages portfolio. Open `index.html` locally for basic development. The asset-validation workflow checks local and remote references on pushes and pull requests.
